# Kabadiwala Connect

A beginner-friendly full-stack starter project with three roles:
- User
- Kabadiwala
- Authorised Recycler

## Requirements
- Node.js 18+
- MongoDB local or MongoDB Atlas (optional; the app uses an in-memory fallback if MongoDB is not configured)

## Run
Open two VS Code terminals.

### Backend
```bash
cd backend
npm install
npm run dev
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```

Open the frontend URL shown by Vite, normally http://localhost:5173.
